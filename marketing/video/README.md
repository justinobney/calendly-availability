# Skill marketing video

A 54-second Remotion composition for introducing `$calendly-availability` to the team.

All captured calendar data is synthetic. Recreate the deterministic demo CSV with:

```bash
python3 scripts/generate-demo-data.py
```

Install and preview:

```bash
npm install
npm run studio
```

Render the MP4 and poster:

```bash
npm run render
npm run still
```

Outputs are written to `out/` and are intentionally excluded from Git.
